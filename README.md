## Built with

- React and TypeScript
- vinext / Vite
- HTML5 and responsive CSS
- Git and GitHub Pages
- Open Graph metadata for professional link previews

## Project structure

```text
portfolio/
├── app/
│   ├── globals.css
│   ├── layout.tsx
│   └── page.tsx
├── public/
│   └── og.png

├── package.json
├── vite.config.ts

├── tsconfig.json

```

`index.html` is the static GitHub Pages build. The original React/TypeScript source is available under `app/`.

## Run locally

Requirements: Node.js 22 or newer.

```bash
npm install
npm run dev
```

Then open the local URL printed in the terminal.

## Build

```bash
npm run build
```
