## Selected work

### Madinah Operations Intelligence

An end-to-end Power BI and predictive analytics case study using **30,000 privacy-safe synthetic service reports**.

**Tools:** Power BI, Power Query, DAX, Python, pandas, NumPy, and scikit-learn.

**Revised holdout evaluation (6,057 resolved reports):** 85.3% recall, 33.6% precision, and 0.6870 ROC-AUC. A time-based review excluded four unverified capacity features and corrected 645 labels that were not available at the original cutoffs. The revised threshold found 148 additional true positives at the cost of 611 additional false alerts. These are synthetic-data evaluation results, not demonstrated real-world effectiveness.

[Read the portfolio case study](https://youmnaeidh.github.io/portfolio/projects/madinah/) · [Source repository](https://github.com/youmnaeidh/Madinah-Operations-Intelligence)

### EventBoard v2

A full-stack Arabic events demo for Madinah with accounts, database-backed demo bookings, favorites, organizer analytics, hybrid recommendations, Arabic search, and synthetic-data registration forecasts.

**Tools:** React, TypeScript, Node/Express, PostgreSQL, Python/FastAPI, and scikit-learn. The frontend uses GitHub Pages; API and AI run on Render Free, with Neon Free PostgreSQL.

## Project structure

```text
portfolio/
├── app/
│   ├── globals.css
│   ├── layout.tsx
│   └── page.tsx
├── index.html            # legacy branch-published homepage, retained for rollback
├── scripts/prepare-pages.mjs
├── .github/workflows/deploy-pages.yml
├── og.png
├── package.json
├── vite.config.ts
├── next.config.ts
├── tsconfig.json
└── README.md
```

`app/page.tsx` is the **single editable source** of the homepage. The
production site is generated by vinext's static export into `dist/client/`.
The root `index.html` is an older branch-published snapshot retained temporarily
as a rollback while Pages publishing is migrated to GitHub Actions; do not edit
it for future site changes.

## Run locally

Requirements: Node.js 22 or newer.

```bash
npm ci
npm run dev
```

## Build and test

```bash
npm run check  # lint, export from React, then validate generated public HTML
npm run export:pages  # create dist/client ready to upload as a Pages artifact
```

GitHub Actions publishes `dist/client/` from `main` once repository
**Settings → Pages → Build and deployment → Source** is set to **GitHub Actions**.
The workflow builds, checks the case-study links and copies the PDF, Open Graph
preview and standalone case studies. Deployment happens only after checks pass.
Do not remove the legacy root `index.html` until Actions publishing is
confirmed live; the prior branch publishing remains available for rollback.

Local static output is exported at `/` by vinext and adjusted for the project
site path `/portfolio/` by `scripts/prepare-pages.mjs`. The deployment workflow
uploads the generated folder, so editing the homepage never requires manual
changes to a second HTML copy.
